🔐 Secure Steganography Web App

This project is a Flask-based web application that allows users to hide and extract secret messages inside:
- Images 🖼
- Audio files 🎵
- Videos 🎥

Features:
- User login & registration
- Password-protected encoding/decoding
- Clean UI
- Supports image, audio, and video steganography

Tech Stack:
- Python (Flask)
- HTML, CSS
- OpenCV (Video Processing)

Developed as part of cybersecurity project.
