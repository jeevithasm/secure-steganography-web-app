## 📌 Overview

A **multi-modal cybersecurity application** that enables secure data hiding using **Image, Audio, and Video Steganography** combined with **AES Encryption** to ensure confidentiality and integrity of hidden information.

---

## 🚀 Features

* 🖼️ Image Steganography (LSB-based)
* 🎧 Audio Steganography (WAV format)
* 🎥 Video Steganography (Frame-based encoding)
* 🔐 AES Encryption with Password Protection
* 🌐 Flask-based Web Application
* ⚠️ Hidden Data Detection System
* 📥 Downloadable Encoded Files
* 🖥️ Hacker Terminal UI

## ⚙️ Installation

```bash
git clone https://github.com/Aaradhana-R/secure-steganography-web-app.git
cd secure-steganography-web-app

# Create virtual environment
python -m venv venv
venv\Scripts\activate   # Windows

# Install dependencies
pip install -r requirements.txt

# Run application
python app.py
```

## 💻 Usage

1. Open the web application in your browser
2. Choose module (Image / Audio / Video)
3. Upload file
4. Enter secret message and password
5. Click **Encode / Decode**
6. Download output file
